# JEV News

JEV News is an experimental Malaysian news reader that collects selected RSS
feeds and evaluates the information reported in political news.

## Releases

No software release is available yet. This repository will provide downloadable
releases, installation instructions, and notes about changes when a version is
ready.

Check the [Releases page](https://github.com/sheng0325/jev-news/releases) for
available versions.

## Feedback

Use [Issues](https://github.com/sheng0325/jev-news/issues) to report bugs or suggest
improvements. Include the release version and steps needed to reproduce a problem.
Do not include API keys or other private information in issue reports.

## Repository scope

This is the public distribution and feedback repository. Development source and
history are maintained separately in a private repository.
